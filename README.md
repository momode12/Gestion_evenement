Gestion d’Événement

Application web et mobile destinée à la gestion complète d’événements, incluant l’inscription des participants, la gestion des paiements et le contrôle d’accès par scan de QR code. La solution est développée avec React.js (TSX) et Tailwind CSS pour l’interface web d’administration, React Native pour l’application mobile de contrôle d’accès, Flask pour le backend et PostgreSQL pour la base de données. L’architecture repose sur une API REST sécurisée permettant la synchronisation en temps réel entre l’interface d’administration et l’application mobile utilisée aux points d’entrée et de sortie.

Les fonctionnalités principales incluent la création et la configuration d’événements (date, lieu, capacité, tarifs), la gestion des participants et des billets avec génération automatique de QR codes uniques, l’intégration des paiements (statut payé / en attente), ainsi que le scan à l’entrée et à la sortie pour le contrôle des accès et le suivi de présence. Le système permet également la gestion des rôles (administrateur, agent de contrôle), la visualisation d’un tableau de bord avec statistiques en temps réel (nombre d’entrées, revenus générés, taux de participation) et l’exportation des rapports financiers et des listes de participants.
